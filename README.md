# MMS Confeitaria

Projeto de site para a confeitaria MMS Confeitaria, com foco em bolos caseiros, doces artesanais e pedidos via WhatsApp.

## Estrutura

- `index.html` — página principal
- `style.css`, `enhancements.css` — estilos do site
- `assets/` — imagens, fontes e ícones
- `bolos-caseiros/`, `doces/`, `nossos-destaques/`, `sobre-nos/` — páginas de seções

## Como usar

1. Abra `index.html` em um navegador.
2. Para editar o conteúdo, altere os arquivos HTML correspondentes.
3. Para atualizar o estilo, edite `style.css` ou `enhancements.css`.
